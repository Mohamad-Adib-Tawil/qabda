# بشارة نور الدين مخملجي

صفحة ثابتة عربية RTL مستوحاة من ترتيب وحركة قالب «قِبضة». كل بيانات المولود والنصوص والروابط ومسارات الصور والفيديو في [site-config.js](site-config.js).

## تشغيل محلي

افتح المجلد بخادم ملفات ثابتة، مثل:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

تهاني الزوار تُحفظ في تخزين المتصفح على الجهاز نفسه، ولا تُرسل إلى خادم. رابط واتساب فارغ في الإعدادات، لذا لا يظهر زر تواصل حتى يضاف رابط صحيح.

## النشر

الموقع يعمل على GitHub Pages من جذر الفرع `main`، ويستخدم مسارات أصول نسبية لدعم مسار المشروع.
